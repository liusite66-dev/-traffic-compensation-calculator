# 交通事故赔偿计算器

一款离线可用的交通事故纠纷赔偿金额计算桌面工具，基于 Electron 构建，自动计算三大类赔偿金额、交强险扣除、诉讼费等，支持导出 Excel。

## 功能

- **医疗费类** — 医疗费（支持逐笔明细）、住院伙食补助费、营养费（含天数及依据选择）
- **死亡伤残类** — 护理费、误工费（含计算备注）、残疾赔偿金、被扶养人生活费、精神损害抚慰金、护理用品费、交通费（支持逐笔明细）
- **财产类** — 财产损失
- **汇总计算** — 三大类赔偿汇总、交强险扣除、被告承担比例、垫付扣除、最终赔付金额
- **诉讼费自动计算** — 按财产案件分段累计规则（≤1万50元 ~ >2000万0.5%），自动分摊原告/被告负担金额
- **其他费用** — 鉴定费、原告三者险应得
- **Excel 导出** — 一键导出包含赔偿汇总、医疗费类明细、死亡伤残类明细、财产类明细四个 sheet 的 xlsx 文件
- **历史记录** — 每次导出自动保存，可随时载入/删除，数据持久化在本地

## 技术栈

- **前端**: 纯 HTML + CSS + JavaScript（单页应用，无框架依赖）
- **桌面壳**: Electron
- **Excel 导出**: ExcelJS（本地加载，完全离线）

## 使用方式

### 开发运行

确保已安装 Node.js，然后：

```bash
# 安装依赖
npm install

# 启动应用
npm start
```

或直接双击 `启动计算器.bat`。

### 构建分发

```bash
# 打包为免安装版
npm run pack

# 打包为 NSIS 安装包（Windows）
npm run build
```

构建产物在 `dist/` 目录下。

## 诉讼费计算规则

依据《诉讼费用交纳办法》第十三条，财产案件根据诉讼请求金额分段累计：

| 区间 | 费率 |
|------|------|
| 不超过 1 万元 | 50 元 |
| 1 万元 ~ 10 万元 | 2.5% |
| 10 万元 ~ 20 万元 | 2% |
| 20 万元 ~ 50 万元 | 1.5% |
| 50 万元 ~ 100 万元 | 1% |
| 100 万元 ~ 200 万元 | 0.9% |
| 200 万元 ~ 500 万元 | 0.8% |
| 500 万元 ~ 1000 万元 | 0.7% |
| 1000 万元 ~ 2000 万元 | 0.6% |
| 超过 2000 万元 | 0.5% |

诉讼费按**法院支持总额 ÷ 原告诉请总额**的比例在原告和被告之间分摊。
